All notable changes to this project. Dates are ISO; results referenced are in REPORT.md.

## [Unreleased] — 2026-10-25 RetinaReach: round 3 of the calibration redesign; cross-fitted systemic probes  (branch `retinareach`)

What the 5-seed Canon sweep (2026-10-24) showed: Canon and the held-out Nikon meet the IDx-DR targets on every seed; the phone ranks well (AUROC 0.913, 0.926 after AdaBN) but fails at the shipped threshold, and full AdaBN cuts its per-patient sensitivity from 0.815 to 0.655; every systemic probe fails the gate, four of them UNDERPOWERED on the handheld test split. This round builds the fixes to test on those checkpoints, no retraining.

- `retinareach.label_free_threshold(q_captures, ref, method, q_reference=None)`: two new methods. `em2` runs EM where the Platt map holds — on the same captures scored under the source profile's statistics (`q_reference`) — and carries the posteriors to the calibrated scores, which set the threshold by expected sensitivity (EM on calibrated scores read the camera's score compression as "little disease here", REPORT 10.8). `rate` is rank-only: flag the top fraction `pi * target_sens + (1 - pi) * (1 - source_spec)` of the captures, immune to compression. `ThresholdReference.source_spec` (specificity at the shipped threshold on source validation) is fit and shipped for it; references written before it load with it unset and `rate` refuses them instead of guessing. `THRESHOLD_METHODS` = shipped, em, anchor, em2, rate. Without a reference, `em2` / `rate` reduce to `em`.
- `retinareach.prevalence_match_weights` / `prevalence_matched_sample`: the label-free prevalence-matched calibration pool. Experiment A showed the pool's disease rate, not the camera, drives AdaBN's sensitivity drop; the device cannot build a source-prevalence pool from labels, but it can from its own posteriors (EM on the source-statistics scores): weights `r * a + (1 - r)` with `a` solved so the pool's expected rate `sum(w r) / sum(w)` is the source's (or zero: predicted disease-free eyes only), then the calibration batches are resampled by those weights. `expected_prev` is the label-free estimate of the pool's rate the device can report; the lowest reachable rate is bounded by how soft the posteriors are.
- `redesign_calibration.py`: experiment **D** (the matched pool, source and zero prevalence, full depth and shallow, at the shipped threshold, with `matched_expected_prev` vs the labels' `matched_actual_prev`); B3 and C run every threshold method on every base, the matched pools included, with the pool under tabletop statistics as the `em2` / `rate` reference; C resamples the matched pool from the same N captures. The camera ladder gains the matched-pool, `shallow + EM2`, `shallow + rate` and `matched + shallow + EM2 / rate` columns and prints specificity beside sensitivity (both IDx-DR endpoints).
- `train_retinareach.py`: `operating_point.csv` and the calibration-size sweep report `em2` and `rate` (the pool and each capture draw are also scored under the source statistics as the reference; `flag_rate` recorded). `score_once.py` re-sets `em2` / `rate` the same way per fold, so `--primary calibrated:em2:<rule>` is available for the Messidor-2 look; a checkpoint whose references predate `source_spec` gets `rate` skipped with a note.
- Cross-fitted systemic probes (`probe_folds.py`; `train_retinareach.py --probe-folds K`, protocol `calibrated_oof<K>`): every probe fit K-fold out of fold over ALL handheld rows (patient-grouped; the trunk stays frozen and never sees a handheld label), C and the sensitivity threshold chosen by inner patient-grouped folds, permuted-label control per fold; the metadata comparator cross-fit on the same folds so the paired delta keeps its rows. On mBRSET that gates nephropathy, neuropathy, MI and smoking on 46 / 55 / 98 / 81 positive patients instead of 7-16. `probe_folds.py --ckpt <seed.pt> --target-root <mBRSET>` does it post hoc on a finished checkpoint and writes `capability_probes_oof.csv` + `predictions_<device>_probes_oof<K>.csv` next to the run; `summarize_retinareach.py` merges those rows into the capability table.
- Phone path: `export_retinareach.py` writes `threshold_reference` and a `calibration` spec (source profile, `shallow_layers` from `--shallow-frac`, default half the BN layers) into `retinareach_profiles.json`. `app/RetinaReachKit`: `calibrate(images, mode: .full | .shallow, thresholdMethod: .shipped | .em2 | .rate)` — shallow mode takes the first K layers' entries from the measured vector and the rest from the source profile (no new graph: the collector's first K entries are exactly those); `em2` / `rate` score the captures under the source profile and under the calibrated statistics and re-set each source target's threshold with the same arithmetic as Python; `screen` flags at the stored threshold when the calibration carries one. `retinareach-cli calibrate --mode shallow --threshold em2`. Defaults unchanged (full, shipped), so the parity check is unaffected.
- Tests: em2 / rate under score compression, the matched pool's rate and its label-free estimate, `cross_fit_probe` (every patient once, both eyes in one fold, controls at chance), experiment D and the five methods in the redesign run, the post-hoc probe folds and their pickup by the summarizer, the in-line `--probe-folds` run, `rate` skipped for a pre-`source_spec` reference in `score_once.py`.

## [Unreleased] — 2026-10-17 RetinaReach: the once-only external test  (branch `retinareach`)

- `score_once.py --dataset messidor2 --root <Messidor2> --checkpoints <frozen *.pt> --primary PROTOCOL:METHOD:RULE`: the frozen checkpoints of one sweep scored on Messidor-2 exactly once. Each of `--folds` (5) patient-grouped folds is scored with statistics re-estimated, labels unread, on the other folds (`--calibration full` = the trainer's AdaBN; `shallow` = the first `--shallow-frac` of the layers from the tabletop profile), so every patient is scored once and inductively; calibrated scores are read at the shipped threshold and at the label-free `em` / `anchor` thresholds re-set from the same fold's pool. Gate rows (comparator = chance: the external labels fit nothing), operating points per method, per-1,000 referral outcomes (`referral_outcomes.py`), per-seed predictions, `once.json`.
- The ledger (`external_test_ledger.json` beside the script, `--ledger`): the look is OPENED before any score exists (dataset, root, checkpoint SHA-256s, code revision, `--plan` SHA-256, the primary result, calibration mode, host, time); nothing about performance is printed until every checkpoint is scored; then it is COMPLETED with the headline numbers. A completed look refuses every later run on that dataset, with no override flag; a look that never completed may be retried with the same checkpoints only. `--preflight` checks data, checkpoints, one forward pass, one calibration and the ledger, and spends nothing; a missing `--primary` or `--plan` file stops before the ledger is touched.
- `referral_outcomes.patient_outcomes`: a patient with no gradable photo now counts as a retake whether or not a grade exists (Messidor-2's ungradable photos carry none); a patient with a result but no grade leaves the denominator.
- Tests: `tests/test_score_once.py`.

## [Unreleased] — 2026-09-24 RetinaReach: self-calibrating, capability-declaring model  (branch `retinareach`, off `disease/metadata-baseline`)

- `retinareach.py`: `RetinaReachNet` — one standard timm trunk (default MobileNetV4-Conv-Small) with one linear head per target; image only, metadata never an input. Source heads (`dr_referable`, `edema`) trained on the tabletop set; systemic targets are linear probes on the frozen, self-calibrated trunk, so the trunk never sees a handheld label. `self_calibrate` = `train_mbrset.adapt_bn` plus an optional Schneider et al. (2020) source prior. Deployable calibration as two graphs: `BatchStatCollector` (batch → every BN layer's batch mean / unbiased variance; its average over batches reproduces AdaBN exactly) and `StatInputNet` (image + statistics vector → per-target probabilities; equals the eval-mode model with those statistics). Label-free camera signature (`camera_distance`: per-channel symmetric KL of the BN Gaussians), `DeviceProfile` with a same-camera envelope, and `device_capability` — the report the phone prints: nearest validated profile's capability, or NOT_VALIDATED for every target when the camera is outside all envelopes.
- `capability_gate.py`: one patient-grouped split per dataset over all rows (`multitask_split`, split seed 42 fixed across training seeds); per-target label-encoding audit (a 1/2-coded binary column is refused, not trained); the metadata comparator refit on that split (strongest of `metadata_model.py`'s logreg / GBM over the intake-form sets `age_sex`, `clinical`, chosen by grouped CV on train+val only; the `full` chart reported, not gating); paired patient-cluster bootstrap of image − metadata AUROC; statuses SUPPORTED / THRESHOLD_DRIFT / NO_IMAGE_EVIDENCE / UNDERPOWERED / NOT_VALIDATED. Standalone CLI prints the bar each target must clear from the label CSV alone.
- `train_retinareach.py`: the whole build for one seed — stage-1 trunk on BRSET, inductive AdaBN profiles from each device's train+val pool, stage-2 probes on calibrated mBRSET embeddings, thresholds fixed on home val, every target × device × protocol (`trained` vs `calibrated`) scored and gated, calibration-size sweep (N captures × repeats × prior); envelopes from pool draws, with device recognition and false acceptance scored out of sample on test-patient captures; writes `capability.csv`, `calibration_sweep.csv`, `profiles.json`, predictions, and the checkpoint.
- `export_retinareach.py`: Core ML `RetinaReach.mlpackage` (image + `bn_stats` input, fp16), `RetinaReachCalibrator.mlpackage` (fp32 by default), optional BN-folded baseline for a fixed profile (`--fused --fused-profile`), `retinareach_profiles.json`; `--verify-images` checks Core ML calibrator+model against PyTorch AdaBN on the same uint8 captures; per-compute-unit latency.
- `run_retinareach.sh` (5 seeds by default), `summarize_retinareach.py` (paired calibrated − trained threshold transfer, multi-seed capability table with a seed-SD noise floor and worst-case status, calibration-size curve).
- `tests/test_retinareach.py` (CPU, synthetic; the Core ML fidelity test runs on macOS only).
